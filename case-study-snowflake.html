The challenge

The reporting warehouse combined Oracle, Informatica PowerCenter and Control-M. It was reliable enough to keep operating, but not efficient enough to scale: 412 tables, 431 mappings across 396 workflows and 94 scheduled jobs needed regular attention. Engineers often began the day investigating overnight failures, while some incoming files were still managed manually.

Moving tables was straightforward. Moving transformation logic was not. An Informatica mapping is a metadata graph, not plain code: transformations run in order, sources and targets are wired through ports, and some expressions retain state from one row to the next. A simple translation could produce SQL that ran successfully but changed the business number.

The solution

Kovift designed an automated conversion pipeline that resolved each mapping into structured data before generating a Snowflake procedure. That gave the conversion agent a correct model of the dataflow instead of an opaque metadata dump.

  • Parsed sources, targets, transformations, ports and links into an ordered graph.
  • Expanded reusable transformations and mapplets so generated procedures included the real business logic.
  • Generated ordered Snowflake procedures, including appropriate patterns for aggregates, merge logic and stateful expressions.
  • Replaced Informatica workflows with SnapLogic ingestion and Snowflake procedures, while retaining Control-M for enterprise dependencies.

Validation was the sign-off gate

Generation alone was never proof. A structural layer checked compilation, source-column coverage, transformation coverage and ordered steps. A second validation framework compared source and target results for the same inputs: row counts, null counts by column, column-level checksums and numeric totals. Exceptions returned with specific context; recurring edge cases went to an engineer.

The outcome

The on-premise Oracle and Informatica footprint was retired. Annual run cost fell by 50%, manual intervention dropped by 80%, and query performance improved by 50%. The team also gained a repeatable validation framework for future pipeline changes.
